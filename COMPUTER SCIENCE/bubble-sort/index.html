How does Bubble Sort work?

01

Compare neighbours

Compare two adjacent elements in the array.

02

Swap if needed

If the first element is larger, swap the two elements.

03

Repeat

Continue comparing neighbouring elements throughout the array.

04

Largest moves right

After every pass, the largest unsorted element reaches the end.
